# Discord Voice Recorder (SKY-MAGYCC)

Discord の会話を自動的に録音し、ブラウザから再生・ダウンロードできるボットです。
このボットは GCP (Google Cloud Platform) 上で安定して動作しています。

## 1. ボットをサーバーに招待する

録音機能を使いたい Discord サーバーにボットを招待します。

- **招待 URL**: 管理者から発行された招待 URL をクリックして、ボットをサーバーに追加してください。
  - ※ 招待には `サーバーの管理` 権限が必要です。
  - ※ ボットに `Administrator` または `ボイスチャンネルへの接続・発言` 権限が付与されていることを確認してください。

## 2. 録音する

ボットがサーバーにいれば、スラッシュコマンドですべての操作が可能です。

### 録音の開始
自分がボイスチャンネルに入った状態で、テキストチャットへ入力します。
```text
/record start
```
- ボットがチャンネルに参加し、録音が開始されます。
- 全員がボイスチャンネルから退出すると、録音は自動的に終了します。

### 録音の停止
手動で録音を止めたい場合は、以下を入力します。
```text
/record stop
```
- 録音された音声は、サーバー側でミックスされ MP3 形式で保存されます。

## 3. 録音データをダウンロードする

保存された音声は、専用のウェブギャラリーで「いつでも・どこからでも」確認できます。

1.  **ウェブギャラリーへアクセス**:
    [http://35.247.18.47:3000/](http://35.247.18.47:3000/) をブラウザで開きます。
2.  **再生とダウンロード**:
    - リストから該当の録音を探します（日時やチャンネル名で確認できます）。
    - プレイヤーで内容を試し聴きし、必要であれば「ダウンロード」ボタンをクリックして保存します。
3.  **整理 (削除)**:
    不要になったデータは「削除」ボタンからいつでも消去可能です。
